# Bundled fonts

The slip is set in Times New Roman, which may not be redistributed. Liberation Serif stands in for
it and travels inside the image, so a render never depends on what happens to be installed on the
machine.

| File | Font | Stands in for | Licence |
| --- | --- | --- | --- |
| `LiberationSerif-*.ttf` | Liberation Serif 2.1.5 | Times New Roman | SIL OFL 1.1 |

Liberation Serif is metrically identical to Times New Roman, so the sheet keeps its widths and its
line breaks.

The licence is beside the fonts. The SIL Open Font License is not the AGPL that covers the rest of
this repository, and it applies to these files alone.
